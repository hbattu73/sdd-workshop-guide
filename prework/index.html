Prerequisites¶

Complete these steps before the workshop to make sure your environment is ready.

The app runs on SQLite — an embedded database file, with no server and no containers. Setup is two commands.

1. Install Tools¶

macOS only — Install Homebrew (if you don't have it)

Step 1 — Check if Homebrew is already installed: 

brew --version
✅ If you see a version number (e.g. Homebrew 4.4.0) — you're done, skip this section.

❌ If you get command not found — continue below.

Step 2 — Install Xcode command line tools: 

xcode-select --install

Step 3 — Install Homebrew: 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Step 4 — Set up Homebrew in your shell: 

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Step 5 — Verify: 

brew --version
# Homebrew 4.4.0

Node.js 22+¶

Node 22 or newer is required

The database driver ships prebuilt binaries for Node 22+. On older versions npm install will fail trying to compile it from source.

brew install node@22
node --version

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node --version

Download and install from nodejs.org

Git¶

brew install git

sudo apt-get install git

Download and install from git-scm.com

2. Clone and Set Up¶

git clone https://github.com/hbattu73/finch-financial.git
cd finch-financial
npm run setup

npm run setup installs dependencies, creates api/.env with working defaults, creates the SQLite database, and seeds it with workshop data. No configuration is needed.

3. Start the App¶

npm run dev

This starts the API (port 3000) and the web app (port 5173) together, with their output colour-coded in one terminal. Stop both with Ctrl+C.

Open http://localhost:5173 and log in with any of the workshop credentials. All users share the password Password123!.

Verify It Works¶

You should see:

  • A list of customer accounts with status badges
  • The ability to filter by account status and name
  • An account detail page with transactions, memos, and audit log

If you can browse accounts and view transactions, you're ready.

Reset data at any time

The seed script is idempotent. To restore the original workshop data at any point, run: 

npm run seed
To start completely fresh, delete the database file and re-run setup: 
rm api/finch.db
npm run setup

Testing¶

Both suites are standalone — no running server and no database setup. Backend tests run the Express app in-process with supertest against a fresh in-memory SQLite database per test file. Frontend tests mock fetch.

Your development data is never touched by a test run.

# Everything
npm test

# One workspace
npm test -w api
npm test -w web

# A specific file, or watch mode
npm test -w api -- accounts.test.ts
npm test -w api -- --watch

Troubleshooting¶

npm install fails building better-sqlite3

Almost always an out-of-date Node. Check your version: 

node --version
If it's below 22, install Node 22+ (see above) and re-run: 
npm run setup

Port 3000 or 5173 is already in use

Another process is holding the port. Find and stop it:

lsof -ti:3000 | xargs kill
lsof -ti:5173 | xargs kill

netstat -ano | findstr :3000
taskkill /PID <pid> /F

Alternatively, set a different API port in api/.env.

npm run dev says dependencies are not installed

Run the setup command first: 

npm run setup

Clone fails with an authentication error

If you see: 

remote: Password authentication is not available for Git operations.
remote: You must use a personal access token or SSH key.
Authenticate using one of the following:

  • SSH key (recommended) — Generate an SSH key and add it to your GitHub account
  • Personal access token — Create a personal access token and use it in place of your password when prompted
